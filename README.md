## Regenerating a PDF

Open the `.html` file in **Chrome**, press `Cmd/Ctrl+P`, then:
- Destination: **Save as PDF**
- Paper size: **Letter**
- Margins: **None** (for the one-page) / **Default** (for the two-page)
- **Background graphics: on** (so the blue accent color renders)
