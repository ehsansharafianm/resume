# Ehsan Sharafian resume

This repository contains two resume implementations:

- [`resume-rendercv/`](resume-rendercv/) is the managed RenderCV workflow. It
  keeps one master YAML and creates a self-contained folder for every tailored
  job application.
- [`manual-version/`](manual-version/) is the custom YAML-to-HTML/PDF system.
  It separates resume information, semantic HTML structure, and professional
  print styling while supporting one tailored folder per job application.

Start with the
[`resume-rendercv` instructions](resume-rendercv/README.md) to create a new
job-specific resume.
